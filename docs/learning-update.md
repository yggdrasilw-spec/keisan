# たしざん にんじゃ：学習画面・復習・レイド連携

## 使い方

- 横長画面では計算とヒントを左右に配置。960×540、1280×720、1366×768、1920×1080で選択・電卓・手書きの表示を検証。縦長画面は従来どおり縦に表示する。
- 詳細設定の既存デバッグモードに「マスター判定（秒未満）」を追加。初期値3.0秒、0.1秒刻み、0.1〜60.0秒。問題記録・宝石・通常コースバッジ・速い回答の演出が同じ判定を使う。既存の厳密な「未満」判定を維持する。神速の制限時間は別設定で変更しない。取得済みバッジは取り消さない。
- 設定の「唱えておぼえる」は初期OFF。直後・最後・両方から選び、1問あたり合計5〜10回を指定する。前半（奇数なら多い側）は答えを表示し、後半は隠す。「1かい唱えた」で進める自己申告方式で、マイクによる認識は行わない。
- 答えを再確認した場合は、答えを隠す練習を最初からやり直す。最後の復習は同じ式を重複させず、終了前に必須で実施。途中終了でも記録済みの誤答を復習する。復習の回数や時間を正答率・マスター・レイド攻撃に加算しない。
- 手書きは、復習ONの場合に認識された誤答を記録して復習へ進む。数字を認識できなかった場合は従来どおり書き直す。
- ホーム下部のレイド欄で、なまえ・すがた・先生のコードを入力して接続。コードは自動復元しない。URLの `?code=ABCD` は自動接続する。正解は10ダメージ、3連続から20、5連続から30。誤答で連続数をリセットする。

## 実装の入口

- `js/00-learning-settings.js`: 永続設定と共通マスター判定。
- `js/17-recitation.js`: 復習画面と設定UI。回答記録処理から独立。
- `js/18-raid.js`: 既存の raid-boss-project / rooms/{code} との接続。接続時だけFirebase SDKを読み込み、匿名認証後に参照する。
- `css/06-learning-layout.css`: 横長画面・復習・レイドの表示。
- `js/02-practice-answer.js`: 全入力方式の回答受付。二重回答や遅延した旧問題の回答を無視する。

特殊モードの旧タイマー実装を除去し、`14-special-modes.js` に集約。ショップの結果フックが特殊モードの処理を消していた初期化順も修正した。保存・バックアップ・初期化に学習設定を含めた。

## 検証

ブラウザはMicrosoft Edge、テストはPlaywrightを使用する。リポジトリをHTTPで配信してから実行する。

```powershell
python -m http.server 8873 --bind 127.0.0.1 --directory .
# 別ターミナル。Playwrightが通常のnode_modulesにない場合だけ、モジュールの場所を指定する。
$env:PLAYWRIGHT_MODULE = 'C:/Users/user/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules/playwright'
node tests/learning-regression.cjs
node tests/raid-regression.cjs
```

`learning-regression.cjs` は画面サイズ、入力方式、全ヒント段階、マスター境界、復習の全設定、二重回答、保存と設定UIを確認する。`raid-regression.cjs` は模擬Firebaseで認証順、全角コード、攻撃、撃破、切断、期限切れ、通信エラーを確認する。実ルームでの接続・攻撃および手書きモデルそのものの認識精度は今回の自動テストの対象外。実ルームは先生の有効なコードを使って確認する必要がある。

## 引き算への展開

まだkeisan2は変更していない。式の表示と問題キーを引き算へ差し替え、アプリ固有の保存キーを分離して同じ復習フロー・レイド接続・横長レイアウトを適用できる。足し算の保存データは流用しない。
