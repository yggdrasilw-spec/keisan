# 引き算幻獣ハンターへの展開

2026-10-03：足し算版のバトル演出完成後、`keisan2` に同様の演出を追加する。

詳細な実装方針は `keisan2/docs/battle-animation-plan.md` に記録した。敵は、そのコースを達成して手に入るバッジ／メダルの幻獣とする。通常7体・コツ35体・神速／超神速8体の既存報酬を参照し、元画像の姿と正式名に合わせた透過PNGスプライトを生成する。

配置・連続技・進行・短い終了演出・スキップ・停止条件・演出設定は足し算版を引き継ぐ。通常完走の勝利演出と既存のメダル付与条件は分離し、採点・時間・報酬・解放条件・保存キーは引き算側を維持する。主人公は既存のハンター4段階、コツの相手も対応する幻獣とする。

引き算の入口は `hikizan_hunter.html`。通常は `ACH_BADGE_DEFS`、コツは `KOTSU_IMG_DEFS`、挑戦は `js/hunter-speed-badges.js` を使い、残存する足し算由来の定義へ接続しない。独立した挑戦モードの回答・終了処理と報酬キューへの接続も検証する。

このコミットには引き算の実装を含めない。移植元の完成仕様・素材形式・検証は [battle-animation-implementation.md](battle-animation-implementation.md) を参照する。
