# 足し算忍者：バトル演出の初版

実装日：2026-10-03。仕様の原本は `battle-animation-plan.md`。

## 実装内容

- 通常20問・ぜんぶ・にがて：問題数に合わせた進行バー。誤答があっても正常完走で勝利。途中終了に勝利は付けない。
- 3連続で手裏剣、5連続で分身。誤答で技の連続数をリセットするが、進行は戻さない。手書きの書き直しは既存仕様を維持し、認識不能を新しい誤答にしない。
- 忍者4成長段階。既存の実績数による成長判定に合わせ、衣装・刀・技・上位のオーラを変える。
- 敵忍者・鎧武者・鬼・天狗・大蛇・龍・師範・木人。区分に対応する竹林・城門・山・森・道場を両端だけに描く。同じ区分の直前の相手を可能な範囲で避ける。
- コツは師範がうなずいて達成を認める。神速は短い攻撃と残像、完走は勝利、誤答・時間切れ・途中終了は撤退。
- 無限は5問ごとに1体、16〜20問はボス。20問で4体、21問から次の周期。失敗した問題・未完了の相手は撃破数に含めない。結果に撃破数を添える。
- 通常終了は最後の斬撃、敵の消滅、納刀を約1.4秒で見せる。「結果へ進む」でスキップ可能。オフ・非表示・通常の途中終了には待ち時間を追加しない。
- 通常・ひかえめ・オフを学習設定に保存する。バックアップ・復元・初期化も既存の学習設定経由で対応。OSの動きを減らす設定では常時動作・オーラを止める。
- ヒント、復習、縦画面、画面離脱では停止する。隠れていた間の攻撃は後でまとめて再生しない。読み上げ対象外・入力を遮らない装飾とする。

## 配置

主画面は幅960px以上・高さ540px以上・縦横比4:3より横長を候補とする。回答パネルの寸法は保ち、横方向に中央へ寄せる。ヒントを開くと元の配置へ戻す。両端のキャラ領域と式・入力・ヒントボタンの実寸を確認し、重なる場合は表示しない。

960×540、1280×720、1366×768、1920×1080の選択・電卓・手書きで確認した。大きい画面では整数倍率を上げる。キャラと風景は固定の両端レイヤーで、中央には描かない。

## 基礎の4画面

ドット・指で数える・Xを作る・数字みつけには、忍者アプリ内の埋め込み時だけ接続する。独立して開いたURLは元の画面のまま。

既存の開始・正誤判定・正常終了・時間切れを通知する。数字みつけの誤タップは進行を増やさない。新しい採点や誤答判定は加えていない。木人と道場を使用し、コース完了後の結果表示・報酬は待たせず、余白がある場合だけ短い達成演出を添える。

基礎画面は教具・ボタンの領域を動かさず、その外の余白だけを使用する。このため通常の1280px幅では非表示、大きな横長画面ではドット・指・Xを作るで表示できる。数字みつけはフィールドが画面いっぱいに広がるため、余白のない配置やヒントONでは非表示になる。画面の学習操作を優先する。

## スプライトと実装の入口

- `img/battle/hero-1.png`〜`hero-4.png`：4列×7行、各行4フレーム。待機・斬撃・手裏剣・分身・被弾・納刀・煙玉。
- `img/battle/ninja.png`、`samurai.png`、`oni.png`、`tengu.png`、`serpent.png`、`dragon.png`、`master.png`、`dummy.png`：4列×5行。待機・攻撃・被弾・撃破・うなずき。
- `img/battle/preview.html`：素材とポーズを選べる開発用プレビュー。HTTPで開く。
- `img/battle/prompts.json`：built-in image_genで使用した生成・修正プロンプトと参照素材。CLI/APIは使用していない。
- `js/21-battle-art.js`：PNGを必要なキャラだけ読み込み、透過フレームを64pxセル・足元y=58にそろえる。最近傍で描画する。読み込み失敗はコード素材にフォールバックする。
- `js/22-battle.js`：通常画面の進行・連続技・表示判定・終了演出。長い演出キューは作らず、最新の反応と終了を優先する。
- `js/23-kiso-battle.js`、`js/kiso-embedded.js`：使い捨ての基礎iframeへの接続。閉じるとその画面の処理ごと終了する。
- `css/10-battle.css`：両端の表示、ヒントの閉じた状態の配置、スキップと設定。

PNGは既存の `ninja_1.png`〜`ninja_4.png` をデザイン参照として新規生成した。元画像を上書きしていない。背景と再利用する技の補助エフェクトはコードで描き、追加の戦闘音は設けていない。装備の見た目反映は計画どおり後続の拡張とする。
